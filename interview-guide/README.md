# Interview guide

Plain-language explanations of how this project works, written so they can be
said out loud. The specs in `docs/` say *what* and *why*; each lab's
`findings.md` says *what happened*; these say **how the pieces connect**.

| File | Answers |
|---|---|
| [01-pipeline.md](01-pipeline.md) | How does a lab actually run? Which machine does what, which program writes which file, and how do they find each other? |
| [02-makefile.md](02-makefile.md) | What is a `make` command, where are they defined, and how does one file drive every lab? |

One guide per question. Add the next one when the next question comes up.
